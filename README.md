# Hi, I’m Twist

I build Windows apps and Android companion tools for video editors, photographers, and small teams. My projects help with the everyday work around a shoot, from sorting footage to sending a quotation.

| Project | What you can do with it |
| --- | --- |
| [TwistTidy](https://github.com/twistkan/twist-tidy) | Sort footage, find duplicate files, and review changes before approving them. |
| [Tweest MediaVault](https://github.com/twistkan/tweest-mediavault) | Browse and search a local photo and video library with cached previews. |
| [Twisted Imagez Starter](https://github.com/twistkan/twisted-imagez-starter) | Manage bookings, prepare quotations, and create invoices with your own business details and optional logo. |
| [Twist MediaBridge](https://github.com/twistkan/twist-mediabridge) | Transfer Android media and back up files from Windows. |
| [TwistType](https://github.com/twistkan/twist-type) | Expand shortcuts into reusable snippets and manage local clipboard history. |
| [MemberPay](https://github.com/twistkan/memberpay) | Track group contributions, receipts, and expenses in a local workspace. |
| [CG Rentals Gear Desk](https://github.com/twistkan/cg-rentals) | Browse and compare camera and rig catalogue prices in a browser. |

Open a project for screenshots, setup instructions, and downloads. If you run into a problem, open an issue on that project and tell me what you were trying to do.

[Buy me a coffee](https://www.yotip.me/twistkan) if one of these apps saved you some time and you’d like to support future updates.
